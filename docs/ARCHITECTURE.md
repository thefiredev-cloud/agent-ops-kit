## 1. Purpose

Agent Ops Kit is a Claude Code plugin for developers who let an AI agent ship code. It bundles three skills, two slash commands, one read-only review subagent and a standard-library Python scanner (`scripts/scrub.py`). The scanner fails the run when text on your deny list, such as a credential or a name, survives into a build you are about to share. The repo ships no build script and no deny list of its own: you supply `build/build.py` and `build/denylist.private.json`.

## 5. Key runtime sequences

### 5.1 /scrub-check before sharing a build

The command refuses to run without a deny list and reports the exit code verbatim.

```mermaid
sequenceDiagram
  autonumber
  actor dev as Developer
  participant cc as Claude Code
  participant cmd as scrub-check command
  participant scan as scrub.py
  participant deny as Deny list
  dev->>cc: /agent-ops-kit:scrub-check dist/public
  cc->>cmd: expand command with target
  Note over cmd: No deny list: stop, point to the example
  cmd->>scan: python3 scrub.py --denylist build/denylist.private.json target
  scan->>deny: load patterns
  deny-->>scan: compiled regexes
  loop each file in target
    scan->>scan: match content and names
  end
  scan-->>cmd: exit 0 clean, 1 findings, 2 usage error
  cmd-->>dev: exit code and output verbatim, file:line per finding
```

## 8. Failure modes and how to see them

| Failure | What the user sees | How to see it | Evidence |
|---|---|---|---|
| Deny list missing, invalid JSON, or empty | Scan refuses to run; never reports clean | stderr line starting `scrub:`, exit 1 | [`scripts/scrub.py#L43-L56`](../scripts/scrub.py#L43-L56) |

## 9. State machine

The life of a public build candidate. Only the owner moves it out of PENDING.

```mermaid
stateDiagram-v2
  direction LR
  [*] --> Source
  Source --> Rejected: build.py public exits nonzero
  Source --> Staged: clean build writes dist/public
  Staged --> Scanned: scrub.py exit 0
  Staged --> Rejected: scrub.py exit 1
  Scanned --> NotSafe: auditor finds anything
  Scanned --> SafeToShare: auditor finds nothing
  SafeToShare --> Pending: PENDING publish
  NotSafe --> Source: fix source, not the pattern
  Rejected --> Source: fix source, not the pattern
  Pending --> [*]: owner publishes by hand
```
